# Nikola Kostelňáková - Portfolio Website

A beautiful and responsive portfolio website showcasing artwork, illustrations, and artistic creations. Built with clean HTML, CSS, and vanilla JavaScript.

## Features

- **Responsive Design** - Mobile-friendly layout that adapts to all device sizes
- **Modern Gallery** - Column-based gallery with hover effects
- **Lightbox Viewer** - Click images to view them in a fullscreen lightbox with descriptions
- **Timeline Section** - Employment history presented in an elegant timeline format
- **Smooth Navigation** - Fixed navbar with smooth anchor scrolling
- **Frosted Glass Effect** - Modern aesthetic with backdrop blur effects
- **SEO Friendly** - Proper semantic HTML structure

## Sections

- **Navigation** - Quick links to all sections
- **Header** - Hero section with title and tagline
- **About** - Artist bio and description
- **Gallery (Tvorba)** - Responsive column layout with artwork
- **Experience (Historie)** - Timeline of employment history
- **Contact** - Contact information and social media links
- **Footer** - Copyright and credits

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required - it's static HTML/CSS/JS

### Customization

Edit the following in `index.html`:
- Update artist name in header
- Modify artwork images in `assets/art/`
- Update descriptions in gallery items (data-title, data-description)
- Edit timeline entries in the experience section
- Update contact information

Edit `style.css` to customize:
- Colors and theme
- Fonts and typography
- Layout and spacing
- Responsive breakpoints
